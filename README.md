# RT-Soviet Combustion (RSC)

[![GPL v3](https://www.gnu.org/graphics/gplv3-127x51.png)](https://opensource.org/license/GPL-3.0)

## 概述

**RT-Soviet Combustion**（以下简称 RSC）是由 **sovietianqi** 独立发起并维护的《尤里的复仇》性能优化引擎扩展，隶属于 **RT Studio**。RSC 从系统调度策略、渲染管线节流、逻辑更新频率自适应等多个技术维度切入，通过进程级资源重分配、计时器精度提升、动态负载均衡以及可见性驱动的 LOD（层次细节）更新机制，为原版引擎提供一套低侵入性的运行时优化方案。

## 当前状态

> ✅ **稳定可用** —— 当前版本已完成核心功能实现，并在多场景下通过稳定性测试，可投入日常使用。后续将持续优化算法参数并增加可配置选项。

## 核心技术特性

RSC 针对原版引擎在单核依赖、定时器分辨率、更新循环效率及目标搜索开销等方面的结构性局限，实施了以下技术改进：

### 1. 进程亲和性掩码重映射

自动检测游戏进程的 CPU 亲和性掩码，若当前被限制于单一逻辑核心，则将其扩展至系统全部可用核心。该操作允许操作系统调度器在多个核心间平衡线程负载，缓解因单核过载引发的指令流水线停顿，但实际收益受限于游戏主循环的串行依赖程度。

### 2. 高分辨率计时器与多媒体类调度服务

- 调用 `timeBeginPeriod(1)` 将系统计时器最小分辨率设为 1 ms，减少 `Sleep` / `WaitForSingleObject` 等等待操作的粒度误差，改善帧间间隔的均匀性。
- 通过 `AvSetMmThreadCharacteristics` 注册多媒体类调度服务（MMCSS），请求“Pro Audio”或“Audio”任务类别。此操作可提升游戏主线程的优先级并赋予更稳定的 CPU 时间片配额，降低因系统后台任务导致的中断频率。

### 3. 基于视口距离与帧率的自适应更新节流

针对单位（`Unit`）、粒子系统（`ParticleSystem`）及动画（`Anim`）的 `Update` 循环，引入空间 LOD 策略：

- 实时采样当前帧率（FPS），若低于预设阈值（如 18 FPS），则进入低帧率模式，进一步降低更新步长。
- 在正常帧率下，计算对象在屏幕空间的投影坐标，以屏幕中心为基准，依据曼哈顿距离划分多个更新间隔等级（例如近处 1~2 帧/次，远处可延至 4~12 帧/次）。
- 通过将对象数组索引与当前帧号取模，实现均匀分散的更新相位，避免所有对象在同一帧集中更新造成的 CPU 瞬时尖峰。

### 4. 紧急绘制剔除

当帧率急剧下降（<10～18 FPS）时，直接跳过 `Anim` 类和 `Overlay` 类的 `Draw` 调用。该策略通过牺牲远距离或低优先级视觉效果，换取宝贵的渲染带宽，优先保障输入响应与逻辑模拟的连续性，属于降级保护机制。

### 5. 目标引用缓存与搜索频率自适应

- 在武器索敌函数（`Greatest_Threat`）中，优先复用已存在的 `Target` 和 `LastTarget` 指针，并对其进行距离与存活状态校验，命中缓存则直接返回，避免触发全图威胁评估的昂贵计算。
- 对 `TechnoClass` 的敌方目标扫描间隔进行动态调整：依据单位类型（步兵、载具、建筑、飞行器）以及当前是否存在目标，将扫描周期设置在 4～30 帧之间。该节流设计在不显著影响 AI 响应延迟的前提下，削减高频扫描带来的冗余 CPU 开销。

### 综合效果

- 同屏单位数量较多时，帧率波动幅度得到一定程度的抑制，周期性卡顿现象有所缓解。
- 在性能受限的硬件上，游戏可保持基本可玩的帧率；在较高配置下，硬件利用率获得更好的发挥。
- 为 MOD 开发者提供更稳定的基准运行环境，降低因引擎原生瓶颈导致的逻辑执行不一致风险。

## 安装指南

RSC 作为 Syringe 插件运行，前置条件为游戏根目录已完成 Ares 扩展部署：

1. 确认游戏根目录存在 `Syringe.exe`
2. 将 `Combustion.dll` 放置于游戏根目录（与 `Syringe.exe` 同级）
3. 通过 Syringe 正常启动游戏

无需追加任何命令行参数或额外运行库依赖。

## 加载验证

游戏启动后，可通过以下方式确认 RSC 已成功加载：

- 观察大型交战场景中帧率曲线的平滑度变化
- 使用第三方帧率监测工具（如 MSI Afterburner / RTSS）记录 FPS 数据进行比较
- 若生成调试日志，可检查其中是否包含 RSC 初始化条目

*未来版本将增加屏幕右下角的引擎标识，便于直观确认加载状态。*
